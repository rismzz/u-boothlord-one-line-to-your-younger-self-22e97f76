One Line to Your Younger Self — one line, 200 characters or fewer, the single line you would send to your younger self. A judge model reads the lines head to head and the best one wins.

> Dear younger me: the fringe was a mistake, he was a mistake, but the Bitcoin at $10 was not. Buy it and stop texting him.

## Run it

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: no network, no randomness, no model calls — the same line every run.
